## Module Eight Journal – Corner Grocer Project

### 1. Summarize the project and what problem it was solving.

The Corner Grocer project was designed to help a grocery store track how frequently customers purchased certain items. The program reads information from an input file and allows users to search for individual items, display the frequency of all items, and view a histogram of purchases. The goal was to organize purchasing information in a way that would help the store better understand customer shopping habits.

### 2. What did you do particularly well?

I believe I did well organizing my program into separate functions and using a class to manage the grocery data. I used a map to store items and their purchase frequencies, which made searching and counting more efficient. I also created a menu that allows users to navigate the program easily. I was especially pleased with getting the histogram to display the purchase frequencies using asterisks.

### 3. Where could you enhance your code? How would these improvements make your code more efficient, secure, and so on?

One improvement I could make would be allowing users to search for items without worrying about capitalization. Currently, the program searches for the exact spelling entered. I could also improve how the program handles unexpected input and add more detailed error messages. These improvements would make the program easier to use and more reliable.

### 4. Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?

One of the more challenging parts was understanding how to read information from a file and store the purchase frequencies correctly. Learning how maps work in C++ also required some practice. I worked through these challenges by reviewing course materials, testing my code, and using debugging techniques to identify problems. I plan to continue using zyBooks, programming documentation, and other educational resources as I develop my skills.

### 5. What skills from this project will be particularly transferable to other projects or coursework?

This project helped me strengthen my understanding of C++ programming, file handling, classes, functions, loops, and data structures. I also gained more experience with debugging and organizing code. These skills will be useful in future computer science courses and software development projects because they provide a foundation for building more complex applications.

### 6. How did you make this program maintainable, readable, and adaptable?

I made my program maintainable by separating different responsibilities into individual functions within the GroceryTracker class. I also used descriptive names, comments, and consistent formatting to make the code easier to understand. This organization makes it possible to update individual features without rewriting the entire program. I believe these practices will help me write better programs as I continue learning software development.
